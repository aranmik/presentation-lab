기본 대치. 행동선, pulse, 숫자 없이 anchor 설계를 얹을 전장 위치만 확인합니다.

궁수 bow anchor → 슬라임 body anchor. Prototype 02의 얇고 조용한 감성은 유지하되 출발점과 도착점을 명확히 둡니다.

전사 front/weapon anchor → 고블린 body anchor. 짧은 arc 단독 대신 긴 연결선을 아주 약하게 보여 “누구를 쳤는지”를 우선합니다.

사제 staff anchor → 전사 heal-point. 공격선과 구분되는 부드러운 곡선과 +숫자 조합을 봅니다.

늑대 snout/front anchor → 전사 hit-point. 적 행동도 source → target 방향성이 즉시 읽히는지 확인합니다.

같은 슬라임에게 피해 숫자 2개가 0.2초 안팎으로 겹치는 상황. 두 번째 숫자는 우상단 offset으로 피합니다.

전사 위치에 회복과 피해 숫자가 가까운 간격으로 뜨는 비교. 색과 위치, 시간차만으로 구분 가능한지 봅니다.

Luda notes

  • Core grammar: `.action-line[data-source][data-target]` plus unit `data-source-anchor` / `data-target-anchor`.
  • Best candidate: archer and priest lines. They read clearly without covering silhouettes.
  • Watch: warrior line must stay low-opacity, otherwise it stops feeling melee.
  • Number queue: 0.15-0.25s delay and a small x/y offset is enough for compact mobile readability.
