기본 대치. source/target anchor 구조와 캐릭터 위치만 확인합니다.

궁수 → 슬라임: straight. 빠르고 정확한 직선은 궁수의 기준 후보로 유지합니다.

사제 → 전사: curve/heal. 직선 대신 감싸는 곡선과 +숫자로 회복 성격을 분리합니다.

전사 → 고블린: slash/connector. source → target 연결을 유지하되, 선 중앙에 베기 arc를 얹어 근접감을 보강합니다.

늑대 → 전사: enemy/slash. 낮고 날카로운 붉은 trail과 작은 claw 느낌으로 적 공격 결을 분리합니다.

숫자 queue: 같은 대상에게 피해 숫자 2개가 뜰 때 두 번째 숫자를 늦게, 우상단 offset으로 띄웁니다.

선 타입 비교: 본게임 이식 시 `.action-line` 공통 구조에 modifier class만 바꾸는 후보입니다.

Luda notes

  • Keep grammar: `.action-line[data-source][data-target]` and unit anchor data stay intact.
  • Best candidates: archer straight, priest curve, number queue offset.
  • Warrior recommendation: weak connector + slash accent. Do not use slash alone.
  • Watch: enemy slash and warrior slash can get noisy if opacity rises.
